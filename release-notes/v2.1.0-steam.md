EasyCommands v2.1.0 — Apex Survival support

- Added Farm Plot, Algae Farm, Oxygen Farm, Food Processor, and Irrigation System selectors, including Half Algae Farms and Half Oxygen Farms.
- Block names with spaces now work naturally: "Farm Plot", "Algae Farm", "Oxygen Farm", "Food Processor", and "Irrigation System". Spaced oxygen/hydrogen tank and generator selectors work too; existing compact names remain supported.
- Read Farm Plot water level, capacity, and fill percentage; check whether a plot contains a plant, whether it is alive, mature, or ready to harvest, and its potential yield and seed requirement. Control the plot's lamp color, radius, intensity, falloff, and blinking.
- Read Algae Farm production rate and time until the next batch, and Oxygen Farm output percentage. An unavailable algae countdown returns -1.
- Queue food recipes using familiar assembler commands. Food Processors inherit assembler controls, including running status and job progress; Irrigation Systems support power controls and production-status readings. Disabled assemblers and Food Processors now correctly report that they are not running.
- Added friendly names for ingredients, meals, seeds/spores, and the anti-radiation kit, plus food, meals, ingredients, and seeds inventory groups. Count and transfer these items with the existing inventory commands.

A few useful details:
- Farm Plot water is measured in liters; percentage values run from 0 to 1. Oxygen Farm percentage is an output factor, not liters per minute.
- Algae production rate is items per minute; countdown is seconds.
- Crop yield is potential output, not a guarantee that a living crop is ready. Check crop state before harvesting. Planting and harvesting still use the game's interactions.
- Food Processor finished items are in output inventory 1. For example: print "Kitchen" inventories[1] amount "kelp crisp"
- If an existing unquoted name uses a newly recognized word such as crop, alive, or dead, put the name in double quotes.

Example commands:
print "Bed" farm plot percentage
tell "Kitchen" food processor to create "kelp crisp"
print "Algae Farm" algae farm countdown
